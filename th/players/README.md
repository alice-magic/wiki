# คู่มือผู้เล่น

ทุกอย่างที่ผู้เล่นต้องรู้: ติดตั้งตัวเปิด เข้าสู่ระบบ หาเซิร์ฟเวอร์ เล่น และเข้าใจข้อความที่ตัวเปิดแสดงระหว่างทาง

---

## ติดตั้ง

ดาวน์โหลดตัวติดตั้งสำหรับระบบของคุณจาก [neko-launcher.com](https://neko-launcher.com) รองรับ Windows, macOS (Intel และ Apple Silicon) และ Linux ตัวเปิดอัปเดตตัวเองอัตโนมัติ ไม่ต้องติดตั้งใหม่เมื่อมีเวอร์ชันใหม่

เปิดครั้งแรกจะให้ยอมรับข้อกำหนดการให้บริการและนโยบายความเป็นส่วนตัว

## เข้าสู่ระบบ

กด **เข้าสู่ระบบ** แล้วเลือกบัญชี Microsoft ที่มี Minecraft: Java Edition ตัวเปิดจะเปิดเบราว์เซอร์ให้ล็อกอินกับ Microsoft และไม่เห็นรหัสผ่านของคุณ

เพิ่มได้หลายบัญชี สลับจากเมนูบัญชีมุมขวาบน รายชื่อเซิร์ฟเวอร์ การตรวจสิทธิ์ และใบสมัครทั้งหมดอิงบัญชีที่เลือกอยู่

**บัญชีออฟไลน์** (ชื่อผู้ใช้โดยไม่ล็อกอิน Microsoft) เพิ่มได้ แต่:

- เซิร์ฟเวอร์ที่เปิด **online mode** จะไม่ให้บัญชีออฟไลน์เล่น ตัวเปิดแสดง *เซิร์ฟเวอร์นี้ต้องใช้บัญชี Minecraft แท้*
- บัญชีออฟไลน์สมัครเข้าเซิร์ฟเวอร์หรือชำระค่าเข้าไม่ได้

## หาเซิร์ฟเวอร์

| ทาง | วิธี |
|---|---|
| **หน้าแรก** | เซิร์ฟเวอร์ทางการแสดงในหน้าแรก กดแล้วกด **เริ่มเกม** |
| **Discover** | ไอคอนเข็มทิศเปิดหน้า Discover: เซิร์ฟเวอร์สาธารณะที่ผ่านการอนุมัติ เซิร์ฟเวอร์ที่กำลังรับสมัคร และแท็ก |
| **ค้นหา** | ช่องค้นหาด้านบนรับชื่อเซิร์ฟเวอร์ รหัสเชิญ หรือโดเมน (ดู [เข้าด้วย IP address](../how-to/join-with-ip-address.md)) |
| **ลิงก์เชิญ** | เจ้าของส่ง `https://neko-launcher.com/j/<code>` ให้ได้ เปิดในเบราว์เซอร์แล้วกด **เปิดใน Neko Launcher** ตัวเปิดจะเพิ่มเซิร์ฟเวอร์ให้ ดู [Deep link](../neko-launcher/deep-links.md) |

## เล่น

กด **เริ่มเกม** ครั้งแรกจะดาวน์โหลดม็อดแพ็ก Java และม็อดโหลดเดอร์ที่ตรงกัน ครั้งต่อไปโหลดเฉพาะที่เปลี่ยน แถบความคืบหน้าแสดงการดาวน์โหลด ปุ่ม **Logs** เปิดหน้าต่างล็อกของเกม

ตัวเปิดจะรักษาอินสแตนซ์ให้ตรงกับเวอร์ชันที่เจ้าของเผยแพร่ ไฟล์ที่เจ้าของทำเครื่องหมาย *ignored* (options รีซอร์สแพ็ก สกรีนช็อต ปุ่มลัด ฯลฯ) เป็นของคุณ ไม่ถูกเขียนทับ

## เมื่อเซิร์ฟเวอร์ถูกล็อก

บางเซิร์ฟเวอร์เป็นส่วนตัวหรือเฉพาะไวต์ลิสต์ คุณยังเปิดหน้าเซิร์ฟเวอร์ดูข้อมูลได้ แต่ **เริ่มเกม** จะกดไม่ได้ และมีข้อความอยู่ด้านล่างจอ ข้อความนั้นเจ้าของเป็นคนเขียน อาจบอกว่าขอสิทธิ์ได้ที่ไหน

ถ้าเซิร์ฟเวอร์ **เปิดรับสมัคร** ข้อความจะลงท้ายด้วย **กดที่นี่เพื่อสมัคร** การสมัครมีแบบฟอร์มสั้นๆ และบางเซิร์ฟเวอร์มีค่าเข้า ดู [สมัครเข้าเซิร์ฟเวอร์](../how-to/apply-to-a-server.md)

## การตั้งค่า

เปิดไอคอนฟันเฟือง:

- **Java และหน่วยความจำ** — ตัวเปิดติดตั้ง Java ที่ตรงกันให้เอง เลือกเองและตั้งขีดจำกัดหน่วยความจำได้
- **ภาษา** — อังกฤษ ไทย ญี่ปุ่น รัสเซีย
- **ปิดไปที่ tray**, **Discord Rich Presence**, ช่องอัปเดต (stable / beta)
- **ตั้งค่ารายอินสแตนซ์** — คลิกขวาที่อินสแตนซ์เพื่อเปิดโฟลเดอร์ ไฟล์ สร้างทางลัดบนเดสก์ท็อป และดูประวัติเวอร์ชัน

## Instance ของคุณเองและ modpack

กด **+** ด้านล่างของแถบด้านข้างเพื่อค้นหา modpack จาก Modrinth, CurseForge, FTB และ ATLauncher นำเข้าไฟล์ `.mrpack` หรือ `.zip` ของ CurseForge หรือสร้าง instance เปล่าด้วย Minecraft และ loader เวอร์ชันไหนก็ได้ ดู [Instance ในเครื่องและ modpack](local-instances.md)

## แก้ปัญหา

| อาการ | ตรวจสอบ |
|---|---|
| *เซิร์ฟเวอร์นี้ต้องใช้บัญชี Minecraft แท้* | คุณอยู่บนบัญชีออฟไลน์ สลับไปบัญชี Microsoft |
| *คุณไม่ได้รับอนุญาตให้เข้าถึงอินสแตนซ์นี้* | เซิร์ฟเวอร์ถูกล็อก ถามเจ้าของ หรือสมัครถ้าเปิดรับ |
| ดาวน์โหลดค้าง | เช็คการเชื่อมต่อ แต่ละไฟล์มีเวลาจำกัด ตัวเปิดจะโหลดต่อเมื่อกดเริ่มเกมครั้งถัดไป |
| เกมปิดทันที | เปิด **Logs** ท้ายล็อกมีพาธของ crash report |
| เล่นผิดบัญชี | บัญชีที่เลือกแสดงที่มุมขวาบน สลับก่อนกดเริ่มเกม |
