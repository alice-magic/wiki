# Deep link

วิธีเปิดเซิร์ฟเวอร์ที่ต้องการในตัวเปิดจากภายนอก: ลิงก์เชิญบนเว็บ URL `nekolauncher://` หรือทางลัดบนเดสก์ท็อป

---

## ลิงก์เชิญ: `neko-launcher.com/j/<code>`

สร้างในแดชบอร์ด (แท็บ **Invites**) เปิดในเบราว์เซอร์จะแสดงชื่อ ไอคอน คำอธิบายของอินสแตนซ์ และมีปุ่ม:

- **เปิดใน Neko Launcher** — ส่ง `nekolauncher://join/<code>` ให้ตัวเปิดที่ติดตั้งไว้ ถ้าไม่มีอะไรเปิดในไม่กี่วินาที หน้าเว็บจะเสนอดาวน์โหลด
- **สมัคร** — เมื่ออินสแตนซ์เปิดรับสมัคร ลิงก์ไป `https://neko-launcher.com/apply/<name>`

ในตัวเปิด รหัสถูกแก้ผ่าน API (ลิงก์ที่เพิกถอนหรือหมดอายุจึงใช้ไม่ได้ทุกที่) อินสแตนซ์ถูกเพิ่มในแถบด้านข้างและเปิดหน้านั้น ผู้เล่นที่ไม่มีสิทธิ์เห็นข้อความ no-access ของเจ้าของ และเมื่อกำลังรับสมัคร ปุ่มสมัคร

รหัสสุ่มโดยค่าเริ่มต้น **รหัสกำหนดเอง** ต้องผ่านอนุมัติ Discovery ของอินสแตนซ์

## URL scheme: `nekolauncher://`

| URL | ผล |
|---|---|
| `nekolauncher://join/<code>` | เหมือนลิงก์เชิญด้านบน |
| `nekolauncher://instance/<name>` | เปิดอินสแตนซ์ที่ผู้เล่นมีอยู่แล้ว (หรือติดตั้งได้) ด้วยชื่อ ปุ่ม *เปิดในตัวเปิด* ของเว็บใช้อันนี้ |

scheme ถูกลงทะเบียนตอนติดตั้ง (Windows, macOS, Linux) scheme เก่า `aml://`, `alicemagiclauncher://` และ `nekolauncherprotocol://` ยังเปิดตัวเปิดได้ ค่าจำกัดที่ `A–Z a–z 0–9 . _ -` และ 64 ตัวอักษร

ถ้าตัวเปิดยังไม่เปิด ลิงก์จะเปิดมันและถูกจัดการเมื่อหน้าต่างพร้อม ถ้าเปิดอยู่แล้ว หน้าต่างเดิมถูกโฟกัส

## ทางลัดบนเดสก์ท็อป

คลิกขวาที่อินสแตนซ์ในตัวเปิด → **สร้างทางลัด** วางทางลัดบนเดสก์ท็อปที่เปิดตัวเปิดด้วย `--instance <name>` ตรงไปที่อินสแตนซ์นั้น

## หน้าสมัคร: `neko-launcher.com/apply/<name>`

แบบฟอร์มสมัครฉบับเว็บ สำหรับผู้เล่นที่ถนัดเบราว์เซอร์ ต้องเข้าสู่ระบบ Microsoft และให้ใบสมัครแบบเดียวกับตัวเปิด
