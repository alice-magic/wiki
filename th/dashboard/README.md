# แดชบอร์ด: เวิร์กสเปซ แพ็กเกจ และสมาชิก

แดชบอร์ดที่ [neko-launcher.com/dashboard](https://neko-launcher.com/dashboard) คือที่ที่เจ้าของเซิร์ฟเวอร์เผยแพร่อินสแตนซ์และจัดการผู้เล่น ทุกอย่างในนั้นอยู่ภายใต้ **เวิร์กสเปซ**

---

## เวิร์กสเปซ

เวิร์กสเปซ = ทีม + แพ็กเกจ เข้าสู่ระบบครั้งแรกจะได้เวิร์กสเปซส่วนตัวบนแพ็กเกจ FREE สร้างเพิ่มหรือรับเชิญเข้าเวิร์กสเปซอื่นได้ สลับจากแถบด้านบน อินสแตนซ์ สมาชิก ลิงก์เชิญ ใบสมัคร และการเรียกเก็บเงิน แยกกันต่อเวิร์กสเปซ

## แพ็กเกจ

แพ็กเกจเป็นการสมัครสมาชิกรายเวิร์กสเปซ ชำระด้วยบัตรหรือ PromptPay (Stripe), PayPal หรือคริปโต ข้อจำกัด ณ เวลาที่เขียน:

| แพ็กเกจ | อินสแตนซ์ | พื้นที่ | ไวต์ลิสต์ | สมาชิก | ขึ้น Discovery | ตรวจสลิปอัตโนมัติ |
|---|---|---|---|---|---|---|
| FREE | 1 | 20 MB | 5 | 1 | – | – |
| SMALL | 2 | 128 MB | 10 | 2 | ✓ | – |
| STARTER | 3 | 256 MB | 25 | 3 | ✓ | – |
| PRO | 10 | 512 MB | 100 | 10 | ✓ | ✓ |
| UNLIMITED | 20 | 4 GB | 1000 | 50 | ✓ | ✓ |

ราคาและรายละเอียดปัจจุบันอยู่ที่หน้า **Plan** ในแดชบอร์ด พื้นที่นับเฉพาะไฟล์ที่คุณอัปโหลด ม็อดจาก Modrinth ไม่นับ ไวต์ลิสต์นับผู้เล่นทุกคนทั่วเวิร์กสเปซ ไม่ว่าเพิ่มเองหรือผ่านการสมัคร

เมื่อแพ็กเกจหมดอายุ ฟีเจอร์ที่ผูกกับแพ็กเกจหยุด (ขึ้น Discovery ตรวจสลิปอัตโนมัติ) และข้อจำกัดกลับมาบังคับ ข้อมูลของคุณยังอยู่

## สมาชิกและบทบาท

แท็บ **Members** เชิญด้วยอีเมล ผู้ถูกเชิญกดยอมรับจากแดชบอร์ดของตัวเอง

| บทบาท | ทำได้ |
|---|---|
| **OWNER** | ทุกอย่าง รวมการเรียกเก็บเงินและลบเวิร์กสเปซ |
| **ADMIN** | ทุกอย่างยกเว้นการเรียกเก็บเงินและความเป็นเจ้าของ |
| **MEMBER** | เฉพาะที่ได้รับสิทธิ์ ตาม permission node |

Permission node ครอบคลุม อินสแตนซ์ (สร้าง ตั้งค่า ไฟล์ เวอร์ชัน ลบ) ไวต์ลิสต์ ตรวจใบสมัคร ประกาศ สมาชิก และ API key สมาชิกของเวิร์กสเปซเจ้าของติดตั้งอินสแตนซ์จากตัวเปิดได้เสมอเมื่อเข้าสู่ระบบบนเว็บด้วยบัญชีเดียวกัน

## API key

**Settings → API key** ออก key หนึ่งอันต่อเวิร์กสเปซให้ปลั๊กอินเซิร์ฟเวอร์ Minecraft อ่านไวต์ลิสต์ ดู [Server API](../neko-launcher/server-api.md) ถือเป็นรหัสผ่าน หลุดเมื่อไรให้สร้างใหม่

## การแจ้งเตือน

กระดิ่งในแถบด้านบนรวมเหตุการณ์ใบสมัคร (ส่ง อนุมัติ ปฏิเสธ ได้รับการชำระ) เจ้าของตั้ง **Discord webhook** ต่ออินสแตนซ์ได้ และผู้สมัครจากเว็บได้รับอีเมล
