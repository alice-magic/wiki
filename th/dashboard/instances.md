# อินสแตนซ์และการตั้งค่า

อินสแตนซ์คือม็อดแพ็กหนึ่งชุด มีไฟล์ ประวัติเวอร์ชัน ไวต์ลิสต์ และการตั้งค่าของตัวเอง หน้านี้อธิบายทุกการตั้งค่าและผลที่มีต่อผู้เล่น

---

## สร้างอินสแตนซ์

**Instances → New instance**: ชื่อที่แสดง คำอธิบาย เวอร์ชัน Minecraft โหลดเดอร์และ build **ชื่อภายใน** (ใช้ใน URL และเป็นชื่อโฟลเดอร์บนเครื่องผู้เล่น) ระบบสร้างให้ อินสแตนซ์ที่สร้างผ่าน API ระบุ slug ตัวพิมพ์เล็กได้

## ทั่วไป

| การตั้งค่า | ผล |
|---|---|
| **ชื่อที่แสดง คำอธิบาย ไอคอน** | แสดงในตัวเปิดและหน้าสมัคร |
| **วอลเปเปอร์** | พื้นหลังหน้าอินสแตนซ์ในตัวเปิด อัปโหลดรูป หรือวิดีโอ (MP4/WebM) ที่จะถูกแปลงเป็นพื้นหลังแบบสตรีม |
| **แท็ก** | ตัวกรองใน Discover (`survival`, `roleplay`, …) |
| **ลิงก์โซเชียล** | ปุ่มใต้คำอธิบาย: Discord, GitHub, YouTube, เว็บไซต์, วิดีโอฝัง, FuriPay handle ดู [ลิงก์โซเชียล](../neko-launcher/social-links.md) |
| **Game arguments** | อาร์กิวเมนต์เพิ่มเติมของเกม เช่น `--quickPlayMultiplayer=play.example.com` เพื่อเชื่อมต่อทันทีที่เปิด |

## ใครเห็นและใครติดตั้งได้

สองการตั้งค่าทำงานร่วมกัน **Visibility** บอกว่าใครเห็น **Enforce whitelist** ล็อกไฟล์ของอินสแตนซ์ที่มองเห็นได้

| Visibility | ขึ้น Discover | ใครติดตั้งได้ |
|---|---|---|
| **PRIVATE** (ค่าเริ่มต้น) | เฉพาะผู้เล่นที่มีสิทธิ์อยู่แล้ว หรือเมื่อกำลังรับสมัคร | ผู้เล่นในไวต์ลิสต์และสมาชิกเวิร์กสเปซ |
| **UNLISTED** | ไม่ เข้าถึงได้ด้วยชื่อหรือลิงก์เชิญ | ทุกคนที่หาเจอ เว้นแต่เปิด *Enforce whitelist* |
| **PUBLIC** | ใช่ หลัง[ผ่านอนุมัติ Discovery](discovery.md) | ทุกคน เว้นแต่เปิด *Enforce whitelist* |
| **OFFICIAL** | ใช่ บนหน้าแรกของตัวเปิด | ทุกคน ไม่สนไวต์ลิสต์ ตั้งได้เฉพาะแอดมิน Neko |

API คำนวณค่า `access` ให้ผู้เล่นที่เรียกด้วยกฎนี้:

```
OFFICIAL                                       → เข้าได้
PUBLIC หรือ UNLISTED ที่ไม่มี enforceWhitelist → เข้าได้
สมาชิกของเวิร์กสเปซเจ้าของ                     → เข้าได้
อยู่ในไวต์ลิสต์ของอินสแตนซ์ (UUID หรือชื่อ)    → เข้าได้
นอกนั้น                                        → ไม่ได้
```

ผู้เล่นที่ไม่มีสิทธิ์ยังเปิดหน้าอินสแตนซ์ในตัวเปิดได้ ปุ่ม **เริ่มเกม** ถูกปิดและแสดง **ข้อความ no-access** ของคุณ ดู [ไวต์ลิสต์และใบสมัคร](whitelist-and-applications.md) สำหรับข้อความและการรับสมัคร

## Online mode

เปิดโดยค่าเริ่มต้น ผู้เล่นบนบัญชีออฟไลน์ (ไม่ใช่ Microsoft) เห็น *เซิร์ฟเวอร์นี้ต้องใช้บัญชี Minecraft แท้* และกดเริ่มเกมไม่ได้ ปิดเฉพาะเซิร์ฟเวอร์ที่รับบัญชีออฟไลน์

## Read-only

เปิดโดยค่าเริ่มต้น ตัวเปิดรักษาไฟล์ที่จัดการทุกไฟล์ให้เหมือนเวอร์ชันที่เผยแพร่: ไฟล์ที่ถูกแก้ถูกคืนค่า ไฟล์เกินในโฟลเดอร์ที่จัดการถูกลบตอนเปิดเกมครั้งถัดไป ผู้เล่นควบคุมพาธในรายการ **ignored** ได้ ปิดสำหรับแพ็กที่ตั้งใจให้ผู้เล่นแก้

## Ignored paths

พาธ (สัมพัทธ์กับโฟลเดอร์อินสแตนซ์) ที่ตัวเปิดเขียนครั้งเดียวแล้วไม่แตะอีก และไม่ลบ: options ของผู้เล่น รีซอร์ส/เชดเดอร์แพ็ก สกรีนช็อต ล็อก config ฝั่ง client ของม็อด มี preset สำหรับม็อด client ยอดนิยม (Sodium, Iris, Xaero, voice chat, …) เพิ่ม `mods/.connector` ถ้าแพ็กใช้ Sinytra Connector: โฟลเดอร์นั้นเป็น cache ต่อเครื่อง ห้ามแชร์

## Hide mods

ปิดโดยค่าเริ่มต้น เมื่อเปิด ตัวเปิดเก็บม็อดของอินสแตนซ์ **นอก** โฟลเดอร์ `mods` บนเครื่องผู้เล่น และส่งให้ม็อดโหลดเดอร์ตอนเปิดเกม ผู้เล่นยังเพิ่มม็อดของตัวเองใน `mods/` ได้ แต่ม็อดที่ซ้ำกับของคุณจะถูกปฏิเสธ รองรับ Fabric, Quilt, Forge และ NeoForge รวมถึงแพ็กที่ใช้ Sinytra Connector ตัวเปิดยังตัดอาร์กิวเมนต์ภายในออกจากล็อกของเกมเพื่อไม่ให้พาธที่ซ่อนถูกพิมพ์

ใช้เพื่อให้แพ็กถูกคัดลอกยกชุดยากขึ้น ไม่ใช่การเข้ารหัส

## ประกาศ

แต่ละอินสแตนซ์มีฟีดประกาศที่ตัวเปิดแสดงเป็นแบนเนอร์ จัดการในแท็บ **Announcements** ดู [ประกาศ](announcements.md)

## Danger zone

**Delete instance** ลบไฟล์ เวอร์ชัน ไวต์ลิสต์ ใบสมัคร และลิงก์เชิญ ย้อนกลับไม่ได้

## สรุปการตั้งค่า

| การตั้งค่า | ค่าเริ่มต้น | ผลต่อผู้เล่น |
|---|---|---|
| Visibility | PRIVATE | หาเจอและติดตั้งได้ไหม |
| Enforce whitelist | ปิด | ล็อกอินสแตนซ์ PUBLIC/UNLISTED ไว้กับไวต์ลิสต์ |
| Online mode | เปิด | บัญชีออฟไลน์เล่นไม่ได้ |
| Read-only | เปิด | ไฟล์ที่จัดการเหมือนเวอร์ชันที่เผยแพร่เสมอ |
| Ignored paths | preset | สิ่งที่ตัวเปิดไม่เขียนทับ |
| Hide mods | ปิด | ม็อดอยู่นอก `mods/` |
| Application mode | CLOSED | ผู้เล่นสมัครได้ไหม |
| Entry fee | ปิด | อนุมัติแล้วต้องชำระเงินไหม |
