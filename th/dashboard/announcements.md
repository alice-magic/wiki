# ประกาศ

แต่ละอินสแตนซ์มีฟีดประกาศที่ตัวเปิดแสดงเป็นแบนเนอร์บนหน้าอินสแตนซ์: แจ้งปิดปรับปรุง อีเวนต์ บันทึกการอัปเดต จัดการในแท็บ **Announcements** ของอินสแตนซ์

---

## เขียนประกาศ

| ฟิลด์ | หมายเหตุ |
|---|---|
| **หัวข้อ** | พาดหัว เพิ่มฉบับภาษาไทย (หรือภาษาอื่น) ใน metadata `th_title` |
| **หมวด** | `NOTICE`, `NEWS` หรือ `EVENT` แต่ละหมวดมีสีของตัวเอง |
| **ลิงก์** | เปิดเมื่อผู้เล่นคลิกแบนเนอร์ |
| **วันที่** | แสดงบนแบนเนอร์ ฟีดเรียงใหม่สุดก่อน |
| **Active** | แสดงเฉพาะที่ active เตรียมไว้ล่วงหน้าแล้วค่อยเปิดได้ |
| **รูป** | รูปแบนเนอร์ ไม่บังคับ ฉบับภาษาคือ `th_imageUrl` |

เปิดหรือปิดแบนเนอร์ทั้งอินสแตนซ์ด้วย **Announcements enabled** ในการตั้งค่าอินสแตนซ์

## ตัวเปิดได้มาอย่างไร

อินสแตนซ์มี `announcementUrl` (`https://api.neko-launcher.com/api/v1/instances/<name>/announcements`) ตัวเปิดดึงตอนเปิดหน้าอินสแตนซ์ พร้อม header ระบุตัวผู้เล่น และ API ตอบเฉพาะประกาศที่ active และผู้เล่นมีสิทธิ์เห็น (อินสแตนซ์ที่ถูกล็อกตอบรายการว่างให้ผู้เล่นที่ไม่มีสิทธิ์)

อินสแตนซ์แบบโฮสต์เองชี้ `announcementUrl` ไปที่ไฟล์ JSON ของตัวเองได้ รูปแบบอยู่ที่ [ฟีดประกาศ](../neko-launcher/announcement-instance.md)
