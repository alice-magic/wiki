# Player guide

Everything a player needs: install the launcher, sign in, find a server, play, and understand the messages the launcher shows along the way.

---

## Install

Download the installer for your system from [neko-launcher.com](https://neko-launcher.com). Windows, macOS (Intel and Apple Silicon) and Linux are supported. The launcher updates itself; you do not need to reinstall for new versions.

On first start you are asked to accept the Terms of Service and Privacy Policy.

## Sign in

Click **Sign in** and choose a Microsoft account that owns Minecraft: Java Edition. The launcher opens your browser for the Microsoft sign-in and never sees your password.

Several accounts can be added; switch between them from the account menu at the top right. Every server list, access check and application is evaluated for the account currently selected.

**Offline accounts** (a username without a Microsoft login) can be added too, but:

- servers with **online mode** on will not let an offline account play; the launcher shows *This server requires a genuine Minecraft account*;
- offline accounts cannot apply to servers or pay entry fees.

## Find a server

| Way in | What to do |
|---|---|
| **Home** | Official servers are listed on the home screen. Click one and press **Play**. |
| **Discover** | The compass icon opens Discover: public servers approved for listing, servers currently recruiting, and tags. |
| **Search** | The search box at the top accepts a server name, an invite code or a domain (see [Join with an IP address](../how-to/join-with-ip-address.md)). |
| **Invite link** | An owner can send you `https://neko-launcher.com/j/<code>`. Open it in a browser and press **Open in Neko Launcher**; the launcher adds the server for you. See [Deep links](../neko-launcher/deep-links.md). |

## Play

Press **Play**. The first launch downloads the modpack and the right Java and mod loader; later launches only fetch what changed. A progress bar shows downloads, and the **Logs** button opens the game log in a separate window.

The launcher keeps the instance in sync with the owner's published version. Files the owner marked as *ignored* (your options, resource packs, screenshots, key binds and so on) are yours and are never overwritten.

## When a server is locked

Some servers are private or whitelist-only. You can still open the server page and read about it, but **Play** is disabled and a message sits at the bottom of the screen. The owner writes that message; it may tell you where to ask for access.

If the server is **taking applications**, the message ends with **Tap here to apply**. Applying takes a short form and, on some servers, an entry fee. See [Apply to a server](../how-to/apply-to-a-server.md).

## Settings

Open the gear icon:

- **Java and memory** — the launcher installs a matching Java automatically; you can choose your own and set the memory limit.
- **Language** — English, Thai, Japanese, Russian.
- **Close to tray**, **Discord Rich Presence**, update channel (stable / beta).
- **Per-instance settings** — right-click an instance for its folder, files, shortcut on the desktop and version history.

## Troubleshooting

| Symptom | What to check |
|---|---|
| *This server requires a genuine Minecraft account* | You are on an offline account. Switch to a Microsoft account. |
| *You are not allowed to access this instance* | The server is locked. Ask the owner or apply if applications are open. |
| Download stuck | Check the connection; a single file has a time limit and the launcher retries on the next Play. |
| Game closes at once | Open **Logs**. A crash report path is printed at the end. |
| Wrong account playing | The selected account is shown at the top right; switch before pressing Play. |

More help: [neko-launcher.com/support](https://neko-launcher.com/support).
