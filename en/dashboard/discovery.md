# Discovery

**Discover** is the launcher's directory of servers: public servers, servers that are recruiting, and tags. Getting listed is a request that Neko admins review.

---

## What appears in Discover

| Instance | Appears because |
|---|---|
| **OFFICIAL** | Always (also on the home screen). |
| **PUBLIC** with discovery **approved** | Listed as a public server. |
| Any locked instance with applications open and listing **OPEN** | Listed as *recruiting*, no approval needed. |
| Any locked instance with applications open and listing **DISCOVERY**, approved | Listed as *recruiting*. |
| Any instance the player already has access to | Shown to that player. |

Players searching by exact name still find UNLISTED and PUBLIC instances that are not listed.

## Requesting discovery

1. Set the instance to **PUBLIC** (or keep it locked and set the application listing to **DISCOVERY**).
2. In the instance settings, press **Request discovery**. This needs a plan with discovery (SMALL and above).
3. The request shows as **Pending**. A Neko admin approves or rejects it; you are notified. A rejected request can be resubmitted.

Approval also unlocks **custom invite codes** (`neko-launcher.com/j/<your-word>`).

## What admins look for

- A working modpack that launches.
- A description, icon and wallpaper that represent the server.
- No content that violates the Terms of Service.
